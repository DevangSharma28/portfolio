About

Ads people finish, then remember

The gap between a good scroll-past and a good install is measured in single-digit frames. That's where I work.

I'm a Unity and web-based game developer who specializes in playable ads — the tiny, fully-interactive game demos that run inside AppLovin, Mintegral, Meta, Google and Vungle networks. Over the past several years I've built campaign after campaign for mobile game studios that needed their core loop working in a 2–5MB file, on low-end Android hardware, in under three seconds to first interaction.

My background spans Unity/C# for native environments and TypeScript + Three.js/WebGL for HTML5 ad networks, so I build the same idea twice — once for the store, once for the ad unit — and make both feel identical to the player.

  • Based in Ahmedabad, India
  • Focus Playable ads & mobile game UX
  • Engines Unity, Three.js, custom WebGL
  • Networks AppLovin, Mintegral, Meta, Google, Vungle
  • Availability Open for freelance & contract

Process

Game Development Process

The same five steps, every campaign, in this order.

01

Concept

Break the app's core loop down to the single mechanic that reads clearly in under three seconds.

02

Prototype

Grey-box the mechanic and get it tappable same-day, before any art is final.

03

Build

Full implementation in Unity or Three.js, with the end-card and install CTA wired in from the start.

04

Optimize

Compress assets, trim code paths, and hit each network's file-size and load-time caps.

05

Ship

Export per-network builds, QA on real low-end devices, and hand off with performance notes.
