About

Little games that happen to be ads

A playable ad gets a few seconds to win someone over before they scroll past. I like working inside that tiny window.

Hi, I'm Devang, a game programmer at Funcell Game Pvt Ltd. I've been there a little over two years, internship included, and in that time I've shipped 55+ playable ads for Android, iOS and WebGL across hyper-casual, idle and plenty of other genres. Most days I'm in Unity with C# or TypeScript with Three.js, and I pick up Cocos Creator when a project needs it.

The work covers a bit of everything: gameplay systems, AI, cameras and UI. Ad networks cap file sizes and these ads have to run on low-end phones too, so I spend a lot of time on object pooling, memory and profiling. I also try to keep the code clean enough that the next project can reuse it.

Process

How I build a playable

Same five steps for every campaign, always in this order.

01

Concept

Boil the game down to the one mechanic someone can understand in under three seconds.

02

Prototype

Get a rough grey-box version playable the same day, before any final art shows up.

03

Build

Build it properly in Unity or Three.js, with the end card and install button wired in from the start.

04

Optimize

Shrink assets, cut code that isn't needed and fit every network's size and load-time limits.

05

Ship

Export a build for each network, test on real low-end phones and hand it over with performance notes.
